# GRASS Tier List Website

Open `index.html` in a browser.

Features:
- Add unlimited players
- Automatically numbers players 1, 2, 3...
- Region selector
- Optional rank field (you decide whether to add one)
- Optional player image URL
- 9 kits: DiaSMP, NethPOT, NethSMP, Sword, Axe, UHC, Crystal, Mace, SpearMace
- Tier choices: LT5, HT5, LT4, HT4, LT3, HT3, LT2, HT2, LT1, HT1
- "No Tier" for untested/empty kits
- Edit/delete players
- Saves automatically in browser localStorage
- Export/import your tier list as JSON

To customize the website, edit `style.css` for the design and `script.js` for the kits, regions, or default data.
