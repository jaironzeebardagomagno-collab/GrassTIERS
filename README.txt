This version adds:

- Editable website title + description
- Players page
- Kit Tier List page
- Top 20 Players page
- Champions Events page
- Optional player rank
- No Tier option
- LT5/HT5 through LT1/HT1
- Editor login demo and edit permissions
- Export/import

DEMO EDITOR CODE:
grass-editor

IMPORTANT:
The permission system in this starter is browser/localStorage based, so it is NOT secure against someone who knows how to inspect the website. For real permissions where only you and selected users can edit, use Firebase Authentication + Firestore Security Rules or Supabase Auth + Row Level Security. GitHub Pages by itself cannot securely protect editing data because it is a static hosting service.
